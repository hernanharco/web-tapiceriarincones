# **App Name**: Tapicería Rincón - Avilés

## Core Features:

- Hero Section with Clear CTAs: A compelling hero section with a high-quality background image, a concise title and subtitle, and prominent call-to-action buttons for immediate engagement.
- Interactive Before & After Gallery: Showcase completed projects through an interactive 'Before & After' slider, highlighting the quality and transformation achieved.
- WhatsApp Contact Button: Implement a 'Click-to-Chat' button that allows users to instantly request quotes via WhatsApp.
- Customer Review Carousel: Display customer testimonials using a carousel to build trust and showcase positive experiences.
- Project description generation: LLM tool which will write a paragraph based on some specific piece of content associated with the before and after photos. This will help customers to engage more deeply with Tapicería Rincón.

## Style Guidelines:

- Primary color: Navy blue (#003366) for titles and buttons, reflecting trust and tradition.
- Secondary color: Vibrant red (#CC0000) to highlight key actions and important elements.
- Accent color: Golden yellow (#FFCC00) used sparingly for icons and visual accents.
- Background color: Light cream or beige (#F5EBCD) to create a warm, classic backdrop.
- Body and headline font: 'Alegreya', a humanist serif with an elegant, intellectual, contemporary feel; suitable for both headlines and body text.
- Use icons related to home and business to differentiate services for particular clients and businesses.
- A clear and intuitive one-page layout that guides users smoothly through key information, from introduction to contact.
